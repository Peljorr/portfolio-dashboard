# ML Portfolio Optimization & Risk Forecasting — Dashboard

Live interactive dashboard for the BIA405 mini-project
(Machine Learning-Based Stock Portfolio Optimization and Risk Forecasting).

**Live URL:** https://<your-github-username>.github.io/<your-repo-name>/

## What this is

A single, self-contained static HTML file (`index.html`). No build step,
no server, no dependencies — all charts are hand-drawn SVG in plain
JavaScript, and all data is embedded directly in the file.

## How to update the dashboard

1. Edit `index.html` directly (or replace it with a newly generated version).
2. Commit and push to the `main` branch:
   ```
   git add index.html
   git commit -m "Update dashboard"
   git push
   ```
3. GitHub Pages automatically redeploys within about a minute — no other
   steps needed.

## Local preview before pushing

Just open `index.html` directly in a browser (double-click it, or
`start index.html` on Windows) — no local server required.
